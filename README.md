# Yadino Backend

Yadino is an open-source productivity platform currently under development.

The project is being built from the ground up with a **.NET backend** and a separate web frontend. It starts as a simple to-do application and is designed to gradually evolve into a broader productivity and workspace platform.

## 🎯 Goal

The initial goal is simple:

**Build a reliable task-management platform.**

The long-term goal is to expand Yadino with functionality commonly found in modern productivity and workspace applications.

Possible future features include:

* Task management
* Notes
* Pages
* Rich content
* Workspaces
* Collaboration
* Productivity tools
* PWA support

## 🏗️ Repositories

Yadino is split into multiple repositories.

### Backend

.NET backend, APIs, business logic, database access, and server-side infrastructure.

👉 [Yadino Backend](https://github.com/CodeBase-WorkSpace/Yadino-Backend)

### Frontend

Web frontend for the Yadino platform.

👉 [Yadino Frontend](https://github.com/CodeBase-WorkSpace/Yadino-Front)

## ⚙️ Backend Stack

* **C#**
* **.NET**
* **ASP.NET Core**
* **Minimal APIs**
* **Entity Framework Core**
* **SQL**

The stack and architecture may evolve as the application grows.

## 🚧 Current Status

Yadino is actively being developed.

The current focus is establishing the backend foundation and implementing the first core features required for the web application.

The project will grow incrementally as new functionality is designed and implemented.
